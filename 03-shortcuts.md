> 💡 Doction is designed for pure keyboard flow. Keep your hands on the home row with these essential shortcuts.

---

## 1. Global Navigation & Workspace

| Action | Windows / Linux | macOS |
|---|---|---|
| **Quick Search & Switcher** | `Ctrl + K` | `Cmd + K` |
| **Collapse / Expand Sidebar** | `Ctrl + /` or `Ctrl + \` | `Cmd + /` or `Cmd + \` |
| **Toggle View / Edit Mode** | `Alt + V` | `Option + V` |
| **Navigate Back in History** | `Alt + Left Arrow` | `Option + Left Arrow` |
| **Navigate Forward in History** | `Alt + Right Arrow` | `Option + Right Arrow` |
| **Print or Export to PDF** | `Ctrl + P` | `Cmd + P` |

## 2. Editor & Text Formatting

| Action | Shortcut |
|---|---|
| **Open Slash Command Palette** | `/` on any blank line |
| **Link to Page (Wikilink)** | `[[` or `/link_page` |
| **Inline Anchored Comment** | `Ctrl + Alt + M` (or `Cmd + Option + M`) |
| **Undo Last Action** | `Ctrl + Z` (or `Cmd + Z`) |
| **Redo Action** | `Ctrl + Y` or `Ctrl + Shift + Z` |
| **Bold Selection** | `Ctrl + B` |
| **Italic Selection** | `Ctrl + I` |
| **Underline Selection** | `Ctrl + U` |
| **Strikethrough Selection** | `Ctrl + Shift + S` |
| **Inline Code Snippet** | `Ctrl + E` |
| **Insert Hyperlink** | `Ctrl + K` on highlighted text |

## 3. Instant Markdown Triggers

Type these prefixes at the start of any line to convert the block instantly:

| Prefix | Resulting Block |
|---|---|
| `# ` | Heading 1 (Large section title) |
| `## ` | Heading 2 (Medium section title) |
| `### ` | Heading 3 (Subsection title) |
| `- ` or `* ` | Unordered Bullet List |
| `1. ` | Numbered Sequence List |
| `[] ` or `[ ] ` | Interactive Task Checkbox |
| `> ` | Pull Quote / Callout Blockquote |
| `---` | Horizontal Visual Divider |
| ````ts` or ````python` | Syntax-Highlighted Code Block |

## 4. Interactive Data Tables

| Keybinding | Action |
|---|---|
| `Tab` | Advance cursor to the next table cell |
| `Shift + Tab` | Move cursor back to the previous table cell |
| `Enter` *(in last row cell)* | Automatically insert a new row below |

## 5. Doction Sketch Draw Studio Shortcuts

### Tool Hotkeys
| Key / Digit | Tool | Action |
|---|---|---|
| `H` or `1` | Hand / Pan | Drag to navigate infinite canvas |
| `V` or `2` | Select | Transform, move, resize, or marquee-select |
| `R` or `3` | Rectangle | Sketch boxes and containers |
| `D` or `4` | Diamond | Draw decision gates and flow nodes |
| `O` or `5` | Ellipse | Draw circles, hubs, and endpoints |
| `A` or `6` | Arrow | Directed connector arrow |
| `L` or `7` | Line | Straight line / divider |
| `P` or `8` | Freehand Pen | Pressure-sensitive calligraphy ink |
| `T` or `9` | Text | Architectural vector typography |
| `E` or `0` | Eraser | 1-Click element deletion |

### Canvas & Transformation Gestures
| Gesture / Key | Action |
|---|---|
| **Canvas Pan** | Two-finger drag or hold `Spacebar` while dragging |
| **Focal-Point Zoom** | `Ctrl + Mouse Wheel` or Trackpad Pinch |
| **Marquee Selection** | Click & drag on empty canvas to group-select |
| **Multi-Select Toggle** | Hold `Shift` while clicking elements |
| **1px Precise Nudge** | `Arrow Keys` (Up, Down, Left, Right) |
| **10px Fast Nudge** | `Shift + Arrow Keys` |
| **Duplicate Elements** | `Ctrl + D` (clones selection with +20px offset) |
| **Layer Ordering** | `]` brings forward; `[` sends backward; `Ctrl + ]` to front; `Ctrl + [` to back |
| **In-Place Text Edit** | Double-click any text element on canvas |
| **Undo / Redo** | `Ctrl + Z` / `Ctrl + Y` (or `Ctrl + Shift + Z`) |
| **Save & Embed** | `Ctrl + Enter` (embeds vector drawing directly into page) |
| **Multi-Stage Escape** | Cancel active draw → Clear selection → Close studio |
